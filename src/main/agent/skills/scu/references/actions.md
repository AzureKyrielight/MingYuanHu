# 写操作前置条件

所有写操作先取单命令 schema，向用户说明目标和影响并取得确认；不要因超时或错误自动重试。附件、照片必须由用户在界面选择，不索取账号凭据。

| 命令                   | 前置条件                                                                                                                         |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `scu_service_submit`   | 先用 `scu_service_form` 按 appId 取动态字段；values 用字段 key，附件在界面上传后使用 {name,url,id}；appId 来自事项地址，不能猜   |
| `scu_ccyl_signup`      | activityId 必须是已确认的活动场次 ID，不是搜索结果的活动库 ID；当前桥缺少详情/订阅命令，无法确认场次时请用户在界面或官方系统办理 |
| `scu_ccyl_cancel`      | 确认已报名场次及取消意图                                                                                                         |
| `scu_repair_submit`    | addressId 来自常用地址；projectId 为项目树叶子 value，名称字段是 label；确认故障描述、预约和照片                                 |
| `scu_passpoint_add`    | 确认 MAC、有效天数与服务；expireDays=0 表示最长有效期                                                                            |
| `scu_passpoint_cancel` | 从设备列表确认 MAC 及解绑意图                                                                                                    |

命令桥未开放云打印上传、缴费、报修撤回与第二课堂订阅等全部业务能力；不要臆造命令，缺失能力请用户在界面或官方系统操作。
