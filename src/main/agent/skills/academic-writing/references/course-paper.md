# 课程论文草稿

## 结构

`draft.json` 只用这些字段，多余字段会被拒绝：

```json
{
  "title": "论文题目",
  "abstract": "第三人称、不分段的摘要，约 400 字",
  "keywords": ["中国式现代化", "乡村振兴", "共同富裕"],
  "sections": [
    {
      "title": "研究背景与问题提出",
      "paragraphs": ["正文段落，一段一个字符串。"],
      "children": [{ "title": "政策脉络", "paragraphs": ["三级标题下的正文。"] }]
    }
  ],
  "references": ["习近平.高举中国特色社会主义伟大旗帜…北京：人民出版社，2022"]
}
```

- `sections` 是二级标题，`children` 是三级标题，最多两级；**不要**在标题里自己写“一、”或“1.1”，渲染时按顺序自动编号。
- `paragraphs` 每项一段，不要在一个字符串里塞多段，也不要写 Markdown 标记。
- `references` 每条一个字符串，按正文 `[1]`、`[2]` 的出现顺序排列；渲染时自动加 `[n]` 前缀。
- 摘要按样张为五号楷体、首行缩进两字符；硬性要求见 `academic_formats` 的 `limits`。

## 内容要求

- 摘要用第三人称叙述（“对……进行了研究”），不分段，约 400 字，不写“本文”“我校”。
- 关键词 3–5 个，用分号分隔，取能代表全文主题的规范词。
- 正文建议 2000 字以上：问题提出、政策与理论依据、现状与问题、对策建议、结语；每节至少两段。
- 引用格式按样张：
  - 专著：主要责任者.书名.出版地：出版者，出版年：页次
  - 期刊：作者.篇名.刊名，年（期）：起止页
  - 报纸：作者.篇名.报纸名，出版日期（版次）
- 只引用确实读过、能核对的文献；不确定的年份、页码、期号宁可不写，也不要补全。

## 常见 warnings

- 摘要字数、关键词数量、参考文献条数不达标：改草稿对应字段后重新 `validateOnly`。
- 正文没有 `[n]`：在论述处标注引用；参考文献为空时不要伪造引用标记。
- 封面缺项：请用户 `dela academic_profile '{"save":{"studentName":"…","studentId":"…"}}'` 保存一次。
- 仍有 XXX、待填写：替换为真实内容或删除占位。
