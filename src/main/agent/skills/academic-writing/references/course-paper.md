# 课程论文草稿

这份结构适用于文学、理工、经管、思政和其他课程。它描述“论文内容”，不规定每门课程必须采用相同的章节；章节、研究方法和引用规范应以课程任务书、教师要求和导入模板为准。

## 结构

`draft.json` 只用这些字段，多余字段会被拒绝：

```json
{
  "title": "课程论文题目",
  "abstract": "按课程要求撰写的摘要；未指定时写成不分段摘要",
  "keywords": ["课程主题关键词一", "关键词二", "关键词三"],
  "sections": [
    {
      "title": "由课程主题决定的章节标题",
      "paragraphs": ["正文段落，一段一个字符串。"],
      "children": [{ "title": "可选的三级标题", "paragraphs": ["三级标题下的正文。"] }]
    }
  ],
  "references": ["确实使用过的文献或课程资料，按课程引用规范填写"]
}
```

- `sections` 是二级标题，`children` 是三级标题，最多两级；**不要**在标题里自己写“一、”或“1.1”，渲染时按顺序自动编号。
- `paragraphs` 每项一段，不要在一个字符串里塞多段，也不要写 Markdown 标记。
- `references` 每条一个字符串，按正文 `[1]`、`[2]` 的出现顺序排列；当前渲染器会自动加 `[n]` 前缀。因此，若课程不要求编号引用，先不要使用当前默认渲染格式，应先提供适配该课程引用规范的模板或扩展。
- 摘要、关键词数量、正文字数、参考文献格式优先服从课程要求；具体模板的硬性限制见 `academic_formats` 的 `limits`。

## 写作流程

1. 先确认课程名称、题目、作业类型、教师给出的章节要求、字数、引用格式和允许使用的材料。
2. 按课程目标建立大纲：理工课程可以使用“原理—方法—结果—分析”，人文课程可以使用“问题—材料—论证—结论”，但不能把这些示例当成固定模板。
3. 每个论断都区分课程资料、外部文献和个人分析。没有读过或无法核对的材料不要写入参考文献。
4. 摘要概括实际写出的内容，不套用其他课程的主题词或政策术语。

## 引用与格式

- 引用格式以任务书、模板或教师要求为准；未提供时，先告诉用户采用的默认格式。
- 只引用确实读过、能核对的文献；不确定的作者、年份、页码、期号宁可标记待核验，也不要补全。
- 学校样张当前给出专著、期刊和报纸格式示例，但这些示例不代表所有课程都必须使用同一套参考文献格式。

## 常见 warnings

- 摘要字数、关键词数量、参考文献条数不达标：改草稿对应字段后重新 `validateOnly`。
- 正文没有 `[n]`：只有在课程引用规范要求编号引用时才添加；不要为了消除 warning 伪造引用标记。
- 封面缺项：请用户 `dela academic_profile '{"save":{"studentName":"…","studentId":"…"}}'` 保存一次。
- 仍有 XXX、待填写：替换为真实内容或删除占位。
- 没有课程模板或教师格式要求时，输出只能说明使用了默认格式，不能声称完全符合任课教师要求。
